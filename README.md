# Visual HTML & Email Architect Pro ✨

עורך ויזואלי מודרני ועוצמתי לקובצי HTML, דפי נחיתה ומיילים שיווקיים (WYSIWYG אמיתי).

## 🚀 מאפיינים מרכזיים:
- **עריכת טקסט ישירה על המסמך (In-line Content Editing)**: לחיצה על כל אלמנט פותחת עריכה חיה במקום, בלי צורך לעבור לשדות חיצוניים.
- **סרגל כלים צף מהיר (Floating Action Toolbar)**: מופיע מעל האלמנט המסומן ומאפשר הדגשה (**B**), הטיה (*I*), הוספת קישורים, הזזה ושכפול.
- **הזזה וסידור מחדש של בלוקים (Move Up / Down & Reorder)**: העלאה או הורדה של שורות ובלוקים שלמים ללא שבירת העיצוב.
- **שכפול ומחיקה מהירה**: בלחיצה אחת על האלמנט הנבחר.
- **פלטת רכיבים מוכנים (Component Palette)**: הוספת כותרות, פסקאות, כפתורים מעוצבים, תמונות, כרטיסי תוכן, קווי הפרדה ו-2 עמודות.
- **תצוגה רספונסיבית מובנית**: מעבר מיידי בין תצוגת מחשב (Desktop), טאבלט, ומובייל (Mobile 375px).
- **תמיכה מלאה בהיסטוריה (Undo / Redo)**: כולל קיצורי מקשים Ctrl+Z ו-Ctrl+Y.
- **ייצוא נקי ותקני (Clean HTML Export)**: מסיר באופן אוטומטי את כל מזהי העריכה, סקריפטים פנימיים וסרגלי הכלים – ומייצא קובץ HTML טהור שמוכן לשימוש ישיר ולשליחה במערכות דיוור (Outlook, Gmail וכו').
- **תמיכה מלאה בעברית וב-RTL**.

## 💻 הרצה מקומית:
פשוט פתח את הקובץ index.html בכל דפדפן אינטרנט מודרני (Chrome, Edge, Firefox, Safari).
